## 重新采集的方法

窗口截图在 macOS 上需要「屏幕录制」权限，无法用键盘 / 菜单自动化完成。步骤：

1. 启动应用并打开样例：`open "build/FU MD.app" Sample.md`
2. 定位窗口编号（无需辅助功能权限）：

   ```bash
   # 列出屏幕上 FU MD 的窗口编号与几何
   /usr/sbin/screencapture -l <窗口编号> -x -o 输出.png
   ```

   窗口编号可用 CoreGraphics 的 `CGWindowListCopyWindowInfo` 读取（`kCGWindowOwnerName` 为 `FU MD`）。
3. 采集窗口本身（`-o` 表示不带阴影），得到 2 倍分辨率 PNG：

   ```bash
   /usr/sbin/screencapture -l <窗口编号> -x -o "docs/03-界面截图/01-主界面-明亮.png"
   ```

4. 需要展示文档下半部分时：点一下编辑区，再用方向键移动光标（编辑器会跟随滚动）。滚轮事件对 WebKit 内容无效，请用方向键。
