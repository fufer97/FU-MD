# FU MD 第三方组件与许可

FU MD 不支持 Markdown 的解析与渲染在应用内自研实现，而是内置 **Vditor** 发行包承担编辑器内核；公式、图表、代码高亮由该发行包内的组件提供。本文档用于说明这些第三方组件的版本、许可与分发义务，供维护者、分发者与使用者核对合规状态。

适用范围：仓库内 `Sources/FUMD/Resources/editor/vditor/` 下的全部第三方资源，以及由它们打包进 `FU MD.app` 的内容；不含本项目自行编写的 Swift 与前端桥接代码。

## 一、组件清单

| 组件 | 版本 | 许可 | 版权方 | 在本项目中的用途 |
|---|---|---|---|---|
| [Vditor](https://github.com/Vanessa219/vditor) | 4.0.0 | MIT | Copyright (c) 2019-present B3log 开源, b3log.org | 编辑器内核（IR 即时渲染模式） |
| [Lute](https://github.com/88250/lute) | 随 Vditor 4.0.0 内置 | MIT | B3log 开源, b3log.org | Markdown 解析引擎（Vditor 依赖，随包内置） |
| [highlight.js](https://github.com/highlightjs/highlight.js) | 随 Vditor 4.0.0 内置 | BSD-3-Clause | Copyright (c) 2006, Ivan Sagalaev | 代码块语法高亮 |
| [KaTeX](https://katex.org/) | 0.16.9 | MIT | KaTeX 项目贡献者 | 数学公式排版 |
| [Mermaid](https://mermaid.js.org/) | 11.16.1 | MIT | Mermaid 项目贡献者 | 流程 / 时序 / 甘特等图表渲染 |

版本号的确定方式：Vditor 4.0.0 由重新下载 npm 发行包并与仓库内 `dist/index.min.js`、`dist/index.css` 做 SHA-256 比对确认（逐字节一致）；KaTeX 与 Mermaid 的版本取自各自压缩包内嵌的版本字符串。

## 三、分发义务与执行方式

| 许可 | 要求 | 本项目如何满足 |
|---|---|---|
| MIT（Vditor / Lute / KaTeX / Mermaid） | 分发时保留版权声明与许可正文 | Vditor 的 `LICENSE` 与 highlight.js 的 `LICENSE` 随仓库与 `.app` 一起分发；应用包内另附本文档 |
| BSD-3-Clause（highlight.js） | 保留版权声明、条件列表与免责声明 | 同上的 `dist/js/highlight.js/LICENSE` 原样保留，未修改 |
| PolyForm Noncommercial 1.0.0（本项目） | 分发时附带条款或条款 URL，并保留 `Required Notice` 行 | 项目根 `LICENSE` 被拷贝进 `FU MD.app/Contents/Resources/LICENSE` |

第三方组件的许可**不因本项目采用 PolyForm Noncommercial 而改变**：Vditor、Lute、KaTeX、Mermaid、highlight.js 仍按各自的 MIT / BSD-3-Clause 许可提供，本项目只是把它们打包分发。反过来，本项目自行编写的代码不因内置 MIT 组件而变为 MIT——两者各自的许可范围互不覆盖。

## 四、内核裁剪说明

仓库内 Vditor 内核是发行包的**裁剪子集**：保留 `dist/css`、`dist/images`、`dist/index.css`、`dist/index.min.js` 与 `dist/js/` 下的 `highlight.js`、`i18n`、`icons`、`katex`、`lute`、`mermaid` 六项；移除 `abcjs`、`echarts`、`flowchart.js`、`graphviz`、`markmap`、`mathjax`、`plantuml`、`smiles-drawer`、`wavedrom` 九个未被调用的渲染引擎，以及 `index.js`、`method.js`、`ts/`、`types/`、`*.d.ts` 等只对二次开发有意义的文件。裁剪后约 11 MB（发行包全量约 23 MB）。

裁剪由 `Scripts/fetch-vditor.sh` 复现，保留清单写在脚本的 `KEEP_JS` 变量里；已实测该脚本重新拉取的结果与仓库内文件逐字节一致。升级 Vditor 时**必须**同步核对本文档的版本号与许可状态。
